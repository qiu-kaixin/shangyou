用户协议与隐私政策

一、隐私政策

1. 一句话总览

尚友默认是一台离线阅读器：不注册、不登录、无账号，学习数据只在你自己的设备上。唯一的例外是「胜迹图 · 题壁」——这项功能默认关闭，只有你（或你所在课堂的组织者）在设置页主动填写一个服务地址后，才会把你在壁上写的内容发往那台由你指定的自建服务。

2. 保存在本机、不会上传的数据

  • 阅读记录、生词本、划线笔记、断句错题、科举成绩、收藏、每日一签与各类偏好设置。
  • 本机写下的题诗、评点与自建景点副本（用于断网时照常使用，联网后按你的操作同步）。
  • 以上数据仅存于本应用的本地存储，开发者不设置服务器接收它们。可在设置页「清空数据」中分类清除，或卸载应用一并删除；「导出备份」生成的 JSON 文件保存在你自己在系统分享面板里选择的位置。

3. 可选的局域网题壁：会传输什么

在设置页填写题壁服务地址并连接成功后，为让同一 Wi-Fi 下的人看见彼此的壁上之作，应用会向该地址发送：

  • 你填写的署名、题诗正文与标题、评点正文；
  • 你建立的景点名称、经纬度与所属省／市／县；
  • 一个随机生成的设备标识（不含手机号、IMEI、MAC、广告 ID 等系统标识符），仅用于区分「哪些是我写的」，以便你删除自己的内容；
  • 上述内容的写入时间与一条内容 ID（用于断网补传时不重复）。

这台服务不由开发者运营：它通常是你自己电脑上的程序，或学校、教师在同一局域网内搭建的服务。开发者不接收、不存储、不分析这些内容，也无从访问该服务。谁搭建服务，谁就是这些数据的管理者；若你在他人组织（如课堂）中使用，请向该组织者了解其保存与清理规则。

连接采用 http 明文，仅适用于可信的家庭或校园局域网。请勿把服务暴露到公网，也请勿在公共 Wi-Fi 中传输任何敏感内容；不填写地址时，应用不会发起任何题壁网络请求。

4. 权限使用说明

  • 网络访问（INTERNET）：Web 版加载内容接口、以及上述可选题壁功能使用；离线阅读、练习、背诵、导出等功能不依赖网络。
  • 通知权限（POST_NOTIFICATIONS 等）：仅当你主动开启「每日提醒」时申请，用于本机定时投递固定文案的提醒，内容不含个人信息，可随时关闭。
  • 本应用不申请定位、相机、麦克风、通讯录、短信、相册、存储读写等敏感权限。

5. 第三方服务与 SDK

  • 应用基于开源框架 React、Capacitor 等构建，这些框架本身不向开发者回传数据。
  • 朗读调用系统自带的文字转语音（TTS）引擎，由系统在设备本地合成；是否收集信息取决于你所选的系统语音服务，我们不经手。
  • 不含广告 SDK、统计分析 SDK、崩溃上报 SDK，不做用户画像与个性化推荐。
  • 「设置 → 关于」提供可选的赞助入口，指向外部赞助平台页面。点击后将离开本应用，该平台按其自身的隐私规则处理信息；本应用不接收你的支付信息，赞助为自愿赠与，不解锁任何内容或功能。

6. 未成年人保护

本应用面向传统文化学习者，中小学生亦可使用。应用不要求填写姓名、年龄、学校、联系方式，也不会主动识别使用者是否为未成年人。若未成年人使用第 3 节的可选题壁功能，其署名与所写内容会发送到该局域网服务，建议由家长或教师组织并告知不要填写真实姓名等个人信息。

监护人可随时在设置页清除本机数据、删除自己写下的题诗与评点，或卸载应用。内容若已同步到自建服务，需由该服务的管理者在服务端删除；应用内删除会同时向已连接的服务发出删除请求。

7. 数据安全与保存期限

本机数据由你设备的操作系统保管，卸载即清除。自建服务上的内容由服务管理者按其规则保存与备份，开发者无法代为删除或设定保存期限。应用不使用加密传输（见第 3 节），请勿在其中填写敏感信息。

8. 你的权利

  • 查看与导出：设置页可导出学习数据备份，题壁内容在页面上直接可见。
  • 删除：可删除自己写下的题诗、评点与自建景点；本机数据可分类清空，或卸载应用。
  • 举报：对他人写下的内容，可在评点旁点「举报」，记录会留在该自建服务供管理者处置。
  • 撤回同意：清空题壁服务地址并停用本功能即可停止后续传输。

9. 政策更新与联系我们

若应用形态变化（例如将来增加账号或由开发者运营的云服务），我们会更新本政策，在应用内显著提示并重新征求同意。

如对本政策有疑问，可通过你下载本应用的应用商店开发者页面联系开发者；应用内「设置 → 关于 → 复制诊断信息」可取得版本与环境信息。

二、用户协议

1. 服务性质

尚友提供古籍原文阅读、注释、白话译文、朗读、练习与「胜迹图 · 题壁」等学习与交流功能。应用本体可完全离线使用；题壁为可选的自建局域网功能，开发者不提供公共服务器、不设账号体系，也不对第三方自建服务上的内容承担运营管理责任。

2. 内容与版权

  • 古籍原文属公有领域财产，供公众自由研读。
  • 应用内的白话译文、注释、讲解、练习题目为原创或整理，配图由AI 生成示意图辅助创作（页面图注已标注），仅供个人学习使用，未经许可不得批量复制、商用或转载。
  • 你写下的题诗、评点与自建景点，权利归你所有；你同意为「同一局域网内互相看见」之目的在该服务上展示。

3. 用户生成内容规范

使用题壁、评点、自建景点功能时，你不得发布下列内容：

  • 违反法律法规、危害国家安全、破坏民族团结、宣扬暴力或淫秽色情的内容；
  • 侮辱、诽谤、骚扰他人，或泄露他人姓名、住址、电话、账号等个人信息的内容；
  • 广告、推广、引流联系方式、刷屏、恶意占位，以及冒充他人或伪造来源的内容；
  • 侵犯他人著作权、商标权等合法权益的内容。

应用与自建服务会对明显的广告、联系方式与违规用语做基础过滤；发现违规内容，任何人都可在评点旁点「举报」。服务管理者（自建者／课堂组织者）可删除违规内容；你也可随时删除自己写下的内容。若内容已同步到服务上，删除请求会一并送达；离线期间的删除会在重新连上后补送。

4. 免责声明

我们尽力校对内容，但古籍整理工作量大，仍可能存在文字、标点或注释疏漏。应用内容仅供学习参考，不建议作为学术引用或权威版本的替代。因设备故障、卸载应用、清理数据或自建服务关闭造成的内容丢失，开发者不承担责任，请善用「导出备份」。

5. 服务的变更与终止

我们可能对应用功能、内容进行更新与调整。因数据保存在你的设备上，卸载应用即意味着服务终止且本地数据随之删除。

6. 联系我们

如对本政策有疑问，可通过你下载本应用的应用商店开发者页面联系开发者；应用内「设置 → 关于 → 复制诊断信息」可取得版本与环境信息。

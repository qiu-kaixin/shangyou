# 尚友 ShangYou

> 颂其诗，读其书，论其世。——《孟子·万章下》
>
> Recite their poems, read their books, and know the times they lived in. — Mencius

**尚友**是一款古诗文分级阅读 Android 应用：2490 篇 / 52 部经典（蒙学、唐诗、古文观止、诗经楚辞、经史子集），配白话段译、逐字训诂、五层详注、背诵与间隔复习、四色划线笔记、科举应试闯关，完全离线可用。

**ShangYou** is a graded-reading Android app for classical Chinese: 2,490 texts across 52 classics with vernacular translations, word-by-word glosses, five-layer annotations, spaced-repetition recitation, margin notes and an imperial-exam quest. Fully offline.
